# Data Manifest

No images are stored in this repository. This file records where every dataset and
weight file came from, so the project can be reproduced exactly.

Raw files are stored read-only in S3 under `data/raw/` and `weights/`.
SHA-256 checksums for every file are in `data/checksums/` (generated by
`scripts/make_manifest.py`, to be written in Phase 1).
